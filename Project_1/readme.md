# ☕ **Project Walkthrough: Coffee Dashboard**
This project showcases a Coffee Sales Dashboard created using Microsoft Excel, which contains various coffee roast types, coffee sizes per kilogram, and sales data from 2019 to 2022 across different countries.

# 🚀 **Project Steps:**
🔍 Data Gathering:
Utilized XLOOKUP and INDEX MATCH functions to gather data from multiple sheets.

🧮 Advanced Formulas:
Applied multiple IF functions for dynamic data processing.

🗓️ Date & Number Formatting:
Cleaned up date and number formats for better clarity and consistency.

🚫 Check for Duplicates:
Ensured data integrity by identifying and removing duplicates.

📊 Range to Table:
Converted raw data ranges to structured Excel Tables for easier management.

📈 Pivot Tables & Pivot Charts:
Created detailed Pivot Tables and Pivot Charts to analyze sales data with proper formatting.

🕒 Timeline:
Inserted and formatted a Timeline filter to analyze sales data over time.

🎛️ Slicers:
Added interactive Slicers for easy filtering of data by country, coffee type, and other variables.

🔄 Updating Pivot Table Data Source:
Ensured the data source for Pivot Tables remains current as data changes.

📊 Dashboard Building:
Designed and built a professional Coffee Sales Dashboard that displays key insights visually.

## 📂 **Key Features:**
Interactive Slicers & Timeline for better user control.

Dynamic Pivot Charts to display trends and country-wise sales.

Clean formatting and intuitive layout for stakeholders.
